# Premium Windows & Doors Website

A modern, responsive website for a UPVC doors, windows, and aluminum products company.

## Features

- Responsive design that works on all devices
- Modern and clean user interface
- Product showcase with detailed information
- Contact form for customer inquiries
- About page with company information
- Mobile-friendly navigation
- Image optimization and lazy loading
- Form validation
- Smooth scrolling and animations

## Pages

1. **Home** (`index.html`)
   - Hero section with call-to-action
   - Featured products
   - Why choose us section
   - Contact CTA

2. **Products** (`products.html`)
   - UPVC Doors
   - UPVC Windows
   - Aluminum Solutions
   - Detailed product information
   - Get quote buttons

3. **About** (`about.html`)
   - Company story
   - Team members
   - Values and mission
   - Call-to-action section

4. **Contact** (`contact.html`)
   - Contact form
   - Company information
   - Google Maps integration
   - Social media links

## Setup Instructions

1. Clone the repository to your local machine
2. Create an `images` directory and add the following images:
   - `hero-bg.jpg` - Hero section background
   - `cta-bg.jpg` - Call-to-action background
   - `upvc-front-door.jpg` - UPVC front door product image
   - `upvc-sliding-door.jpg` - UPVC sliding door product image
   - `upvc-casement.jpg` - UPVC casement window product image
   - `upvc-tilt-turn.jpg` - UPVC tilt & turn window product image
   - `aluminum-sliding.jpg` - Aluminum sliding system product image
   - `aluminum-folding.jpg` - Aluminum folding system product image
   - `about-story.jpg` - About page story image
   - `team-1.jpg`, `team-2.jpg`, `team-3.jpg` - Team member images

3. Update the following information in the files:
   - Company name
   - Contact information
   - Social media links
   - Google Maps embed URL
   - Product descriptions and features
   - Team member information

4. Test the website locally by opening `index.html` in a web browser

## Customization

- Colors can be modified in the CSS files
- Images can be replaced with your own
- Content can be updated to match your business
- Contact form can be connected to your backend
- Google Maps embed can be updated with your location
